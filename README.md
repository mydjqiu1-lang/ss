# 无限流框架原型（光球角色）

这是一个受到《无限恐怖》/无限流启发的轻量游戏框架原型，核心目标：

- **角色可视化**：用不同颜色、大小的「光球」表示不同人物。
- **流程结构**：按“主神空间（准备）→ 副本挑战（生存）→ 结算与成长”的循环推进。
- **可扩展性**：通过数据配置添加新角色、新副本、新事件。

## 核心系统

1. **角色系统（Survivor）**
   - `name`：角色名
   - `color`：光球颜色
   - `size`：光球尺寸（影响初始生命）
   - `stats`：生命、精神、战斗、感知、幸运

2. **副本系统（Instance）**
   - 每个副本有主题、危险等级、事件池。
   - 每回合触发随机事件，角色按属性进行判定。

3. **事件系统（Event）**
   - `combat`、`trap`、`resource`、`mental` 四类。
   - 事件成功/失败会改变生命、精神、积分。

4. **成长系统（Upgrade）**
   - 通过积分升级角色属性。
   - 可加入天赋树、道具、羁绊等扩展。

## 运行方式

直接打开 `index.html`，或在目录执行：

```bash
python3 -m http.server 4173
```

然后访问：`http://localhost:4173`

## 交互说明

- 点击 **「新增光球角色」**：随机生成不同颜色+大小角色。
- 点击 **「开始下一幕副本」**：推进无限流一幕，触发事件并记录日志。
- 点击 **「重置循环」**：清空进度并重新开始。

## 后续可扩展方向
